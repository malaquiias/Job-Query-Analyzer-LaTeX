\section{Descrição do Dataset}%
\label{sec:DescriodoDataset}%
Dataset público do Kaggle com vagas de Engenheiro de Dados no Brasil (LinkedIn, 2023), arquivo \texttt{engenheiro\_de\_dados\_6k.csv}. Os documentos são os textos da coluna \texttt{job\_description}.\par%
\subsection{Limpeza: vagas duplicadas}%
\label{subsec:Limpezavagasduplicadas}%
O arquivo tem 1614 linhas com descrição. 812 são a mesma vaga (mesmo \texttt{job\_id}) extraída mais de uma vez, e outras 38 são vagas diferentes com o texto idêntico. Depois de remover as duas, restam 764 descrições únicas, que são as usadas no ranking.\par

%
\section{Metodologia}%
\label{sec:Metodologia}%
\textbf{Query (perfil ideal):} \textit{data engineer with experience in python and sql}\par\medskip%
\textbf{Grupos:} São Paulo (363 vagas) e Remotas (86 vagas).\par\medskip%
\textbf{TF-IDF:} a query e as vagas de cada grupo viram vetores com o peso de cada palavra. \textbf{Similaridade de cosseno:} mede o ângulo entre o vetor da query e o de cada vaga; ângulo de 0\textdegree{} (cosseno 1) seria um texto idêntico.\par

\section{Discussão}%
\label{sec:Discusso}%
Para esta query, a vaga mais aderente está no grupo \textbf{Remotas} (similaridade 0.3236, contra 0.1863 no outro grupo).\par\medskip%
\textbf{Efeito das duplicatas:} sem a limpeza, das 10 primeiras posições 5 seriam cópias de outra vaga em São Paulo e 8 nas Remotas. Cópias têm exatamente o mesmo score, então ocupam o topo do ranking sem trazer informação nova.\par
